Latihan UTS Struktur Data
Repository ini berisi proses saya mengerjakan kumpulan latihan soal untuk persiapan Ujian Tengah Semester (UTS) mata kuliah Struktur Data menggunakan C++.

Repository ini saya gunakan untuk menyimpan hasil latihan sekaligus melihat perkembangan pengerjaan saya dari soal pertama sampai soal terakhir.

Awal Pengerjaan
Latihan dimulai dengan beberapa soal yang membahas implementasi struktur data dalam sebuah kasus.

Setiap soal memiliki permasalahan yang berbeda, sehingga saya mencoba mengerjakannya satu per satu sambil memahami struktur data yang digunakan dan bagaimana konsep tersebut diterapkan dalam program C++.

Soal 1 - Antrean Pendaftaran Pasien
Pada soal pertama, saya membuat program untuk mengatur antrean pendaftaran pasien di rumah sakit.

Struktur data yang digunakan adalah Queue berbasis Linked List dengan konsep FIFO (First In First Out).

Pada bagian ini saya mempelajari bagaimana sebuah data pasien dapat masuk ke antrean, bagaimana pasien pertama dipanggil terlebih dahulu, dan bagaimana seluruh isi antrean dapat ditampilkan.

Dari soal pertama ini, konsep utama yang saya pelajari adalah:

Queue
FIFO
Linked List
Struct
Pointer
Soal 2 - Antrean Token Ekspresi Aritmatika
Setelah memahami queue menggunakan linked list, pada soal kedua saya kembali menggunakan konsep Queue, tetapi dengan implementasi yang berbeda.

Pada soal ini program menerima sebuah ekspresi aritmatika kemudian memisahkan ekspresi tersebut menjadi beberapa token.

Token dapat berupa operand maupun operator, kemudian disimpan ke dalam queue berbasis Array of Struct.

Dari soal kedua ini, saya berlatih mengenai:

Queue
Array
Struct
Pengolahan string
Pemisahan operand dan operator
FIFO
Soal 3 - Simulasi Direktori
Pada soal ketiga, struktur data yang digunakan mulai berbeda.

Saya membuat simulasi sederhana sebuah direktori atau folder. Program dapat membuat folder baru, melihat isi folder, masuk ke suatu folder, dan kembali ke folder sebelumnya.

Beberapa perintah yang digunakan antara lain:

mkdir <nama_folder>
ls
cd <nama_folder>
cd ..
Pada bagian ini saya mulai mempelajari bagaimana hubungan antar-node dapat digunakan untuk membentuk struktur hierarki seperti folder pada komputer.

Konsep yang saya pelajari:

Tree
Node
Parent dan Child
Sibling
Pointer
Soal 4 - Antrean Pesanan Toko Online
Pada soal keempat, saya kembali mempelajari Queue, tetapi kali ini menggunakan Circular Queue dengan Array Dinamis.

Program mensimulasikan antrean pesanan pada toko online. Pesanan dapat dimasukkan ke antrean kemudian diproses berdasarkan urutannya.

Berbeda dengan queue sebelumnya, pada bagian ini saya harus memahami bagaimana posisi awal dan akhir queue dapat berputar kembali ketika mencapai batas array.

Konsep yang saya pelajari:

Circular Queue
Dynamic Array
Pointer
FIFO
Dynamic Memory Allocation
Soal 5 - Kamus Binary Search Tree
Soal terakhir menggunakan Binary Search Tree (BST).

Pada soal ini saya membuat sebuah program kamus sederhana yang dapat menyimpan kata beserta artinya.

Program dapat melakukan pencarian kata melalui struktur BST dan juga menyimpan riwayat beberapa pencarian terakhir.

Bagian ini menjadi latihan untuk memahami bagaimana data dapat disusun dalam bentuk tree sehingga proses pencarian dapat dilakukan berdasarkan struktur tersebut.

Konsep yang saya pelajari:

Binary Search Tree
Node
Pointer
Searching
Array
Riwayat pencarian
