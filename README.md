# Latihan UTS Struktur Data

Repository ini berisi kumpulan program latihan untuk persiapan Ujian Tengah Semester (UTS) mata kuliah Struktur Data.

Program dibuat menggunakan **C++** dengan fokus pada implementasi berbagai struktur data seperti **Queue, Linked List, Tree, Circular Queue, dan Binary Search Tree (BST)**.

## Daftar Latihan

### Soal 1 - Antrean Pendaftaran Pasien
Implementasi sistem antrean pasien rumah sakit menggunakan **Queue (FIFO) berbasis Linked List**.

Fitur:
- Menambahkan pasien ke antrean
- Memanggil pasien dari antrean
- Menampilkan seluruh pasien yang sedang mengantre

Konsep:
- Queue
- FIFO
- Linked List
- Pointer

---

### Soal 2 - Antrean Token Ekspresi Aritmatika
Program untuk memproses ekspresi aritmatika menjadi kumpulan token menggunakan **Queue berbasis Array of Struct**.

Fitur:
- Menerima ekspresi matematika
- Memisahkan operand dan operator
- Menyimpan token ke dalam queue
- Menampilkan token secara FIFO

Konsep:
- Queue
- Array
- Struct
- Parsing String

---

### Soal 3 - Simulasi Direktori
Simulasi sederhana struktur folder/direktori menggunakan struktur **Tree berbasis Pointer**.

Perintah yang tersedia:
- `mkdir <nama_folder>` - Membuat folder baru
- `ls` - Melihat isi folder aktif
- `cd <nama_folder>` - Masuk ke folder
- `cd ..` - Kembali ke folder induk

Konsep:
- Tree
- Parent dan Child
- Sibling
- Pointer

---

### Soal 4 - Antrean Pesanan Toko Online
Implementasi antrean pemrosesan pesanan menggunakan **Circular Queue dengan Array Dinamis**.

Fitur:
- Menambahkan pesanan
- Memproses pesanan
- Menampilkan antrean
- Menampilkan penggunaan kapasitas antrean

Konsep:
- Circular Queue
- Dynamic Array
- Pointer
- Dynamic Memory Allocation

---

### Soal 5 - Kamus Binary Search Tree
Program kamus sederhana menggunakan **Binary Search Tree (BST)** serta array untuk menyimpan riwayat pencarian.

Fitur:
- Menambahkan kata dan arti
- Mencari kata
- Menampilkan arti kata
- Menyimpan 5 riwayat pencarian terakhir

Konsep:
- Binary Search Tree
- Tree Traversal/Search
- Array
- Pointer
